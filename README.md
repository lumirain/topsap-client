# TopSAP Client

天融信 NGVONE 系列 SSL VPN 的开源替代客户端。**不依赖厂商任何二进制**。

> 起因：厂商客户端的 Electron 界面问题很多且无源码可修。本项目从零实现协议栈，
> 提供一个干净、可维护、可脚本化的客户端。

## 协议文档

完整协议说明见 [docs/PROTOCOL.md](docs/PROTOCOL.md)，包含：
HTTP 接口、登录字段语义、隧道分帧格式、握手时序、已验证的边界。

其中有两个反直觉但关键的结论：

1. **口令在应用层是明文**，前端那套 RSA/Base64 不会出现在报文里
2. **网关不校验 `HASH` 字段内容**，只要求字段存在且格式合法

## 快速开始

```bash
node src/client.js
```

首次运行会拉取验证码到 `captcha-final.png`，把识别结果写入 `code.txt`，
脚本检测到后自动继续登录并建立隧道。会话会缓存在 `session.json`，30 分钟内可复用。

环境变量：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `TS_GW` | `vpn1.sunline.cn` | 网关地址 |
| `TS_PORT` | `4431` | 网关端口 |
| `TS_USER` | - | 账号 |
| `TS_PASS` | - | 密码 |
